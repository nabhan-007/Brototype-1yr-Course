# MongoDB Exam Resources

## Knowledge

- [MongoDB Official Documentation — CRUD Operations](https://www.mongodb.com/docs/manual/crud/)
  Primary reference for all query syntax. Use for: practical query writing.
- [MongoDB Official Documentation — Aggregation Pipeline](https://www.mongodb.com/docs/manual/aggregation/)
  Stage-by-stage reference with examples. Use for: aggregation practical questions.
- [MongoDB University — M001: MongoDB Basics](https://learn.mongodb.com/learning-paths/mongodb-basics)
  Free official course. Use for: structured video explanations of every concept.
- [MongoDB Official Documentation — Indexes](https://www.mongodb.com/docs/manual/indexes/)
  All index types with creation syntax. Use for: index explainer questions.
- [MongoDB Official Documentation — Replication](https://www.mongodb.com/docs/manual/replication/)
  Replica set architecture. Use for: failover/replication oral questions.
- [MongoDB Official Documentation — Sharding](https://www.mongodb.com/docs/manual/sharding/)
  Shard key concepts and architecture. Use for: sharding theory.
- [Wikipedia — CAP Theorem](https://en.wikipedia.org/wiki/CAP_theorem)
  Concise explanation with diagrams. Use for: CAP theorem oral questions.
- [MongoDB Official Documentation — Transactions](https://www.mongodb.com/docs/manual/transactions/)
  Multi-document ACID transactions. Use for: transaction questions.
- [BSON Specification](https://bsonspec.org/)
  Official BSON spec. Use for: JSON vs BSON distinctions.
