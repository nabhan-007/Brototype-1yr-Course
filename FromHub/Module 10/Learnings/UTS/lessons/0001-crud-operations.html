Lesson 1: CRUD Operations

Mission tie-in: You will be asked to write queries live. This lesson gives you the muscle memory.

1. Setup — Start mongosh

Open a terminal and run:

mongosh
use shop

use shop switches to (or creates) the shop database. Confirm with db.

2. Create (Insert)

db.products.insertOne({
  name: "Notebook",
  price: 1.99,
  stock: 100,
  tags: ["stationery", "paper"]
})

db.products.insertMany([
  { name: "Pen", price: 0.99, stock: 200, tags: ["stationery"] },
  { name: "Backpack", price: 49.99, stock: 30, tags: ["bags", "travel"] },
  { name: "Desk Lamp", price: 24.99, stock: 50, tags: ["electronics"] }
])
Key points:
  • Each doc gets an auto-generated _id (ObjectId) — you can also set it manually
  • insertMany() with an empty array throws an error
  • Documents can have different fields (dynamic schema)

3. Read (Query)

db.products.findOne({ name: "Notebook" })

db.products.find({ price: { $lt: 10 } })

db.products.find({ tags: "stationery" })

db.products.find({}, { name: 1, price: 1, _id: 0 })

db.products.find().sort({ price: -1 }).limit(2)
Remember: { name: 1, _id: 0 } is a projection. 1 = include, 0 = exclude. _id is included by default unless you 0 it.

4. Update

db.products.updateOne(
  { name: "Pen" },
  { $set: { price: 1.29 }, $inc: { stock: -10 } }
)

db.products.updateMany(
  { tags: "stationery" },
  { $push: { tags: "office" } }
)

db.products.updateOne(
  { name: "Eraser" },
  { $set: { price: 0.49, stock: 150 } },
  { upsert: true }
)

5. Delete

db.products.deleteOne({ name: "Desk Lamp" })

db.products.deleteMany({ stock: { $lte: 0 } })

Check yourself

Write the mongosh command for each (try from memory first):

1. Insert a product "Mouse" at $14.99 with stock 75.

Answer 
db.products.insertOne({ name: "Mouse", price: 14.99, stock: 75 })

2. Find all products under $20 and show only name and price.

Answer 
db.products.find({ price: { $lt: 20 } }, { name: 1, price: 1, _id: 0 })

3. Increase every product's price by 10%.

Answer 
db.products.updateMany({}, { $mul: { price: 1.10 } })

4. Insert multiple products at once.

Answer 
db.products.insertMany([
  { name: "Keyboard", price: 39.99 },
  { name: "Monitor", price: 199.99 }
])

5. Delete all products with 0 stock.

Answer 
db.products.deleteMany({ stock: 0 })

6. Practice for the Exam

  1. Open mongosh and create a database test_exam
  2. Insert 5 products with different fields (name, price, stock, category)
  3. Run: find all, filter by price range, sort by price descending
  4. Update one doc with $set + $inc
  5. Upsert a document that doesn't exist yet
  6. Delete documents below a threshold
  7. Say out loud what each command does as you type — this builds oral fluency
