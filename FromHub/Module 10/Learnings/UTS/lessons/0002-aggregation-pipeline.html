Lesson 2: Aggregation Pipeline

Mission tie-in: Aggregation is a favourite practical exam topic — expect "write a pipeline that groups and sorts."

1. The Pipeline Concept

Documents flow through stages. Each stage transforms and passes to the next:

db.collection.aggregate([
  { $stage1: ... },
  { $stage2: ... },
  { $stage3: ... }
])

Order matters — $match first to reduce documents early, $sort before $group for accurate $first/$last.

2. Core Stages

$match — Filter (like WHERE)

db.orders.aggregate([
  { $match: { status: "delivered", total: { $gte: 50 } } }
])

Same syntax as find(). Put $match as early as possible.

$group — Group + Aggregate (like GROUP BY)

db.orders.aggregate([
  { $group: { _id: "$status", count: { $sum: 1 }, avgTotal: { $avg: "$total" } } }
])

_id is the grouping field. Prefix with $ to reference a field.

$sort — Reorder

{ $sort: { avgTotal: -1 } }   // -1 = descending, 1 = ascending

$project — Reshape

{ $project: { name: 1, priceWithTax: { $multiply: ["$price", 1.18] }, _id: 0 } }

$unwind — Flatten Arrays

// Input doc: { name: "Order1", items: ["a", "b", "c"] }
{ $unwind: "$items" }
// Output: 3 docs, one per item

$lookup — Join Collections

db.orders.aggregate([
  {
    $lookup: {
      from: "customers",
      localField: "customerId",
      foreignField: "_id",
      as: "customer"
    }
  }
])
// Adds a "customer" array field with matched docs

3. Practical: Build a Report

Imagine a collection sales:

db.sales.insertMany([
  { product: "Laptop", category: "Electronics", amount: 1200, date: ISODate("2026-01-15") },
  { product: "Mouse", category: "Electronics", amount: 25, date: ISODate("2026-01-16") },
  { product: "Shirt", category: "Clothing", amount: 35, date: ISODate("2026-01-17") },
  { product: "Laptop", category: "Electronics", amount: 1300, date: ISODate("2026-02-01") },
  { product: "Shoes", category: "Clothing", amount: 80, date: ISODate("2026-02-05") }
])

Task: Write a pipeline that:

  1. Filters sales for Electronics only
  2. Groups by product name
  3. Calculates total amount per product
  4. Sorts by total descending
Solution 
db.sales.aggregate([
  { $match: { category: "Electronics" } },
  { $group: { _id: "$product", totalSales: { $sum: "$amount" }, count: { $sum: 1 } } },
  { $sort: { totalSales: -1 } }
])

Quick Quiz

1. Which stage filters documents early? Why put it first?

Answer

$match. Putting it first reduces the number of documents flowing through later stages, making the pipeline faster.

2. What's the difference between $group and $sort?

Answer

$group aggregates documents by a key (reduces count). $sort reorders documents (same count).

3. Write a pipeline to get the average sale amount per category.

Answer 
db.sales.aggregate([
  { $group: { _id: "$category", avgAmount: { $avg: "$amount" } } }
])

4. What does $unwind do?

Answer

Deconstructs an array field — creates one output document per array element.

5. How is $lookup similar to SQL JOIN?

Answer

Both combine documents from two collections based on a matching field. $lookup adds the joined data as an array field.
