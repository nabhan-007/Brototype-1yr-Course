# Build a web application

Build a web application using Node.js, Express, and MongoDB, implementing CRUD operations and incorporating all previously learned concepts.

### Project Requirements

1. User Application:
   - Login, Signup, and Home Page.
   - Store user data in MongoDB.
   - Validate login credentials.
2. Admin Panel:
   - Admin login with validation.
   - View, search, create, edit, and delete user data.
   - Manage sessions and cookies securely.

### Implementation Guidelines

1. Authentication & Authorization: Secure login and role-based access.
2. Routing: Use Express Router for organized routes.
3. Middleware: For logging, authentication, and error handling.
4. Project Structure: Separate Routes, Controllers, Models, and Services.
5. ES6 Classes: Modular and scalable code.
6. Overall, a well rounded site.
